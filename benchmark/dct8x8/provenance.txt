## Reference build

CUDA reference (nvcc 12.5, sm_70):

    export PATH=/usr/local/cuda/bin:$PATH
    cd dct8x8-ref-src/dct8x8-cuda
    nvcc -std=c++17 -Xcompiler -Wall -arch=sm_70 -O3 main.cu kernels.cu DCT8x8_gold.cu -o dct8x8_cuda_ref

OpenMP reference (g++ 13.2; `omp target teams` offload pragmas are ignored by g++, so this runs the
teams loop on the host — a functional check, not a tuned CPU baseline):

    cd dct8x8-ref-src/dct8x8-omp
    g++ -O2 -fopenmp -std=c++17 main.cpp kernels.cpp DCT8x8_gold.cpp -o dct8x8_omp_ref

## Reference run

    CUDA_VISIBLE_DEVICES=<idx> ./dct8x8_cuda_ref <width> <height> <repeat>

The reference `Verify()` prints the relative L2 norm against `DCT8x8CPU` and PASS iff `< 1e-6`.
Reference results (GV100, fwk394) at 8192x8192: forward 0.99 ms (rel L2 3.55e-08),
inverse 0.99-1.09 ms (rel L2 8.44e-08); at 999x777: ~0.010-0.014 ms (rel L2 3.55e-08 / 8.45e-08).
